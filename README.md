# FPGA Vision Tracking Gimbal

## 项目简介

本项目是一套基于 FPGA 的双轴视觉跟踪云台系统。系统使用 OV5640 摄像头采集图像，通过肤色分割、邻域滤波和分块连通区域分析定位目标，再根据目标与画面中心的偏差控制水平和俯仰舵机。

当前方案属于基于肤色和区域规则的目标定位，不包含人脸身份识别，也未使用卷积神经网络。

## 主要功能

- OV5640 图像采集与 DDR3 缓存。
- 800×480 彩色 LCD 显示及红十字目标标记。
- 肤色阈值分割与 3×3 多数滤波。
- 分块连通区域筛选、多帧确认与坐标平滑。
- 双轴增量式 PI 跟踪控制。
- 坐标超时保护和舵机指令限幅。

## 硬件配置

| 器件 | 说明 |
| --- | --- |
| FPGA 开发板 | 正点原子达芬奇 Pro |
| 工程目标芯片 | XC7A35TFGG484-2，使用前需核对实物 |
| 摄像头 | OV5640 |
| 显示屏 | 800×480 RGB LCD |
| 执行机构 | 两只位置型微型舵机与双轴支架 |

## 工程目录

- `rtl/`：顶层、摄像头、DDR、LCD 和舵机控制模块。
- `prj/`：Vivado 工程、约束、IP 配置和图像处理模块。
- `sim/`：仿真源文件。
- `doc/`：设计资料。

## 打开与运行

1. 下载完整仓库并解压，保持目录结构不变。
2. 使用兼容的 Vivado 版本打开 `prj/ov5640_lcd.xpr`。
3. 核对目标芯片、引脚约束和硬件连接。
4. 检查 IP 状态，按需重新生成 IP 输出文件。
5. 运行综合、实现并生成 Bitstream。
6. 下载至开发板，先验证图像与目标坐标，再测试舵机。

本仓库不包含编译缓存和生成结果。精简后的工程尚未完成独立环境下的干净重建验证。

## 舵机接口与安全

当前工程约束：

- 水平 PWM：D16。
- 俯仰 PWM：E13。
- 舵机使用外接电源，并与开发板共地。

接线前必须断电。不要将舵机外接电源正极接入开发板信号引脚。
舵机方向、初始位置和脉宽限幅必须根据实际安装调整，避免撞击支架或拉紧线材。

## 已知限制

- 对光照、背景颜色、距离和姿态变化较敏感。
- 手、脖子和肤色相近的物体可能造成误检。
- 分块定位和平滑处理会引入量化误差和跟踪延迟。
- 当前微分系数为零，实际运行的是 PI 控制。
- 实际转动角度需标定，不能直接由 PWM 数值保证。
